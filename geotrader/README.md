# GeoTrader — Market Intelligence Terminal

Streamlit is gone. The dashboard is now three independent, static pieces
that read one JSON file:

```
RAOSABINTEGRATION/                  <- your repo root (data lives here)
├── Broad_index_data/               <- one JSON per broad index (D/W/M mixed, "Timeframe" field)
├── sectorial_index_data/           <- one JSON per sector index (same mixed-timeframe shape)
├── stockdata_15/                   <- one JSON per FNO stock, 15-minute candles
├── stockdata_1H/                   <- 1-hour candles
├── stockdata_D/                    <- daily candles
├── stockdata_W/                    <- weekly candles
├── stockdata_M/                    <- monthly candles
└── geotrader/                      <- everything below lives here
    ├── engine.py                   <- calculation engine -> writes output/result.json
    ├── requirements.txt
    ├── symbol_map.json             <- stock -> sector(s) mapping
    ├── index.html                  <- dashboard shell (structure only)
    ├── styles.css                  <- "Signal Deck" design system
    ├── app.js                      <- dashboard rendering logic
    ├── output/
    │   └── result.json             <- generated by engine.py, read by app.js
    └── refresh.yml                 <- optional GitHub Actions workflow (see below)
```

## 1. Data format this engine expects

**`stockdata_15 / 1H / D / W / M`** — one file per symbol, a flat JSON array:

```json
[
  {"datetime": "2026-08-27T08:45:00.000Z", "symbol": "NSE:ABB",
   "open": 7521.0, "high": 7541.0, "low": 7494.0, "close": 7494.0, "volume": 47830.0},
  ...
]
```

**`Broad_index_data` / `sectorial_index_data`** — one file per index, but every
record is tagged with which timeframe it belongs to, so a single file holds
daily, weekly and monthly candles together:

```json
[
  {"Timeframe": "D", "datetime": "2022-08-18T03:45:00.000",
   "symbol": "NSE:BANKNIFTY", "open": 39324.4, "high": 39703.7,
   "low": 39291.1, "close": 39656.1, "volume": 137211137.0},
  ...
]
```

The engine auto-detects both shapes, is case-insensitive on column names
(`Open`/`open`/`o`, `datetime`/`Original_Index`/`date`, etc.), and splits the
mixed-timeframe index files by their `Timeframe`/`timeframe` field.

## 2. `symbol_map.json`

Maps each FNO stock to the sector(s) it belongs to, used for the Sector
Explorer and Sector Terrain panels:

```json
[
  {"Stocks": "TCS", "Sectors": ["CNXIT"]},
  {"Stocks": "AXISBANK", "Sectors": ["BANKNIFTY", "NIFTYPVTBANK", "CNXFINANCE"]}
]
```

A stock can belong to more than one sector. Without this file, every FNO
stock still shows up in the KPI/RSI/momentum/intraday panels — only the
Sector Explorer and Sector Terrain will be empty.

## 3. Running the engine

```bash
cd geotrader
pip install -r requirements.txt
python engine.py
```

By default it looks for the data folders one level up from `geotrader/`
(i.e. the repo root) and writes `geotrader/output/result.json`. Both are
overridable:

```bash
python engine.py --root /path/to/RAOSABINTEGRATION --out /path/to/result.json
```

Run it manually whenever you want fresh numbers, or schedule it (cron, a
GitHub Action, Task Scheduler) to refresh `result.json` automatically —
see `refresh.yml` for a ready-made GitHub Actions workflow that runs the
engine a few times during NSE market hours and commits the updated JSON.

### What it calculates
- % change (latest vs previous daily close) for broad indices, sector
  indices, and every FNO stock
- RSI(14), Bollinger Bands(20, 2σ), CPR + Camarilla pivots for every
  symbol/timeframe combination
- Advance/decline breadth across the FNO universe
- FNO top-5 / bottom-5 movers, and per-sector top-5 / bottom-5 leaderboards
- Momentum streaks (≥2 consecutive up- or down-closes)
- A multi-timeframe RSI scanner (15m / 1H / Day / Week / Month) with
  BULLISH / BEARISH / NEUTRAL / CHANGE_NOW states
- Intraday first-break signals: a daily or weekly high/low break,
  confirmed by at least one of RSI / Bollinger / CPR / Camarilla on the
  same candle, scanned over the last 7 days

## 4. Viewing the dashboard

`app.js` fetches `output/result.json` with `fetch()`, so the page must be
served over HTTP — browsers block `fetch()` on `file://` pages:

```bash
cd geotrader
python -m http.server 8000
```

Then open **http://localhost:8000/index.html**. Click **Refresh** in the
header any time after re-running `engine.py` to pull the latest data
without a full page reload — it also auto-refreshes every 5 minutes.

### Deploying on GitHub Pages
Since your data and code already live in the same repo, GitHub Pages can
serve this directly:
1. In repo Settings → Pages, set the source to the `main` branch,
   folder `/geotrader` (or point Pages at the whole repo and link to
   `/geotrader/index.html`).
2. Make sure `geotrader/output/result.json` is committed and up to date
   — either run `engine.py` locally and push, or use `refresh.yml` to
   keep it current automatically.

### Design — "Signal Deck"
A dark trading-terminal instrument panel: an animated radar-sweep mark,
a faint contour grid backdrop, brass/amber signal accents against a deep
ink-blue hull, and tabular monospace numerals throughout so figures stay
aligned. No chart library or external JS dependency — every bar chart,
the breadth gauge, and the heat terrain are hand-rolled SVG/canvas/CSS,
styled from the same token set in `styles.css` (`:root { --brass, --bull,
--bear, --hull-0, ... }`). Change the variables there to re-theme the
whole dashboard.

### What's on it
- Animated logo mark + scrolling ticker tape of FNO top/bottom movers
- KPI strip: F&O universe size, breadth %, best/worst mover
- Broad market & sector index panels, each row a diverging bar
- A radial advance/decline gauge — the dashboard's signature element
- FNO top-5/bottom-5 bar chart
- Sector Explorer — 4 independent dropdowns, each showing that sector's
  top/bottom movers
- Sector Terrain — a heat-tile grid, tile shade = that sector's average
  daily % change
- Momentum streak badges (🔥 up / 🧊 down)
- RSI(14) scanner with timeframe + state filter chips and an inline RSI bar
- Intraday signal feed — breakout/breakdown events from the last 7 days

## Notes on what changed from the original Streamlit script
- All `streamlit`, `st.*`, and `plotly.express` code is gone.
- The Hindi motivational-quotes ticker, background image, and logo were
  Streamlit-specific decoration and were not carried over — the new
  dashboard has its own visual identity ("Signal Deck") instead.
- Data source changed from per-timeframe **parquet** files under
  `market_data/{broader_index,sector_index,fno}/{tf}/*.parquet` to your
  actual GitHub layout: **JSON** files under `Broad_index_data/`,
  `sectorial_index_data/`, and `stockdata_15/1H/D/W/M/`.
- The sector map moved from an `.xlsx` file to `symbol_map.json`
  (list-of-`{Stocks, Sectors}` form), matching what's already in your repo.
- All indicator math (RSI, Bollinger, CPR, Camarilla, momentum streaks,
  intraday first-break scan) was preserved from the original script.
