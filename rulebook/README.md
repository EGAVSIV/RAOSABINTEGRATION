# Trading Rulebook

`index.html` is a GitHub Pages rulebook. It can read `rules.json` publicly and can save rules/attachments directly through the GitHub Contents API when the admin supplies a GitHub Personal Access Token in the page.

For saving, use a fine-grained GitHub token with **Contents: Read and write** permission for `EGAVSIV/RAOSABINTEGRATION`. The token is kept only in browser memory for the current page session and is never written into the repository.
